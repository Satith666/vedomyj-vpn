# VEDOMYJ VPN

Программа для Windows, которая сама настраивает VPN по твоим подпискам. Она проверяет серверы, выбирает лучший, подключается и следит за соединением. Российские сайты идут напрямую, заблокированные — через VPN.

## Запуск

Выбери любой вариант:

- **Установщик** `VedomyjVPN-<версия>-setup.exe` — проще всего. Python ставить не нужно, он уже внутри. Программа ставится в папку пользователя без прав администратора, ярлыки появляются на рабочем столе и в «Пуске». Чтобы обновить программу, запусти установщик новой версии — настройки и подписки сохранятся. Удалить: «Параметры → Приложения → VEDOMYJ VPN → Удалить».
- **Портативная версия** `VedomyjVPN-<версия>-portable.zip` — распакуй куда угодно (хоть на флешку) и запусти **VedomyjVPN.exe**. Python тоже внутри, в систему ничего не ставится.
- **Исходники** (эта папка) — нужен Python 3.10 или новее с [python.org](https://www.python.org/downloads/), при установке отметь **Add python.exe to PATH**. Запусти **start.bat**.

Откроется компактное окно программы. Вставь ссылку на подписку и нажми «Добавить» — сразу появится список серверов с пингом. Нажми большую кнопку или «Автонастройка», программа всё сделает сама.

Ядро Xray и списки заблокированных сайтов программа скачает сама. Дополнительные библиотеки ставить не нужно.

У часов Windows появляется значок программы. Если закрыть окно, VPN продолжит работать: открыть окно снова — двойной щелчок по значку, выйти — правой кнопкой → «Выход». Если нужно, чтобы закрытие окна завершало программу, выключи «Работу в фоне» в «Функциях».

## Главное окно

- **Большая кнопка** подключает и отключает VPN. Рядом пинг, скорость и страна выхода.
- **Полоса проверок** под ней — четыре коротких ответа: **Данные** (идут ли через VPN настоящие данные), **Способ** (как программа подключается к серверу: обычный или подобранный отпечаток TLS и маскировка), **Сертификаты** (нет ли подмены) и **Утечки**. Зелёная точка — всё хорошо, жёлтая — есть замечание, красная — проблема, серая — ещё не проверялось. Нажми на полосу — откроется экран **«Состояние»**.
- **Автонастройка** сама скачает нужное, проверит серверы и сервисы и подключит лучший сервер.
- **Маршрутизация** (выпадающий список):
  - «Всё через VPN» (по умолчанию) — весь трафик через сервер, российские сайты — напрямую. Так сайты работают целиком: видео, картинки и загрузки идут через VPN, даже если провайдер их только замедляет, а не блокирует;
  - «Экономный» — через VPN только заблокированное, остальное напрямую. Меньше трафика через сервер, но на сайтах, которые провайдер тормозит, видео может не грузиться.

  Если программа обновилась со старой версии, где по умолчанию был «Умный» режим, она один раз сама переключит на «Всё через VPN» и напишет об этом в журнале. Вернуть «Экономный» можно в этом же списке.
- **Подключение** (выпадающий список):
  - «Системный прокси» — браузеры и большинство программ;
  - «Только порты» — только программы, где прокси указан вручную;
  - **TUN** — через программу идёт весь трафик компьютера, включая игры и звонки (подробнее — ниже).

- **Движок** (выпадающий список) — какие VPN использовать: «Авто» (по умолчанию), Xray, Hysteria2, sing-box (TUIC, AnyTLS) или AmneziaWG. Подробнее — в разделе «Движки».

  У каждого пункта в списках есть кнопка «Подробнее»: там простыми словами написано, что это и когда выбирать.
- **Плитки:** Автопереход, Мультисервер, Без рекламы (работает и без VPN), Шифрование DNS.
- **Обход замедлений YouTube и Discord:** переключатели Zapret и ByeDPI и список «Способ обхода» над ними (подробнее — ниже).
- **Серверы** — ниже. Нажми на сервер, чтобы переключиться. Значки над списком:
  - проверить пинг всех серверов;
  - замерить скорость лучших;
  - обновить подписки;
  - сортировка;
  - «+»: добавить подписку, отдельный сервер или **свой сервер (VPS)**.
- **EN / RU** вверху справа переключает язык.

## Дополнительно

- **Zapret** и **ByeDPI** — подбор стратегии, проверка, свои сайты, обновления.
- **Советы** — рекомендации и пошаговая инструкция, как подключить Telegram.
- **Данные для подключения** — адреса SOCKS5/HTTP для ручной настройки программ, кнопки «Скопировать», порты, доступ для телефона и других устройств в домашней сети.
- **Сервисы и сайты:**
  - **«Проверить сайт»** — вставь адрес, и программа проверит его напрямую, через VPN и через другие серверы, а потом сама добавит правило, чтобы сайт открывался. Закрыт блокировщиком рекламы — разрешит его. Не открывается через этот сервер — пустит через другой, а если ни через один — напрямую. Если сайт отвечает, но в браузере всё равно не работает (просит выключить VPN, капча по кругу), под результатом можно выбрать, как его открывать;
  - проверка популярных сервисов и выбор, как подключаться к каждому (колонка «Маршрут»).
- **Свои правила** — для любого сайта свой способ подключения, свои прокси и списки текстом для опытных.
- **Трафик** — какие сайты открыты сейчас и как они идут.
- **Поделиться** — файл настроек для другого компьютера и QR-коды для телефона.
- **Функции** — все переключатели с подробными объяснениями.
- **Обновления** — для серверов, списков сайтов и ядра можно отдельно выбрать, как часто обновлять, или обновить по кнопке.
- **Журнал** и **Настройки** — язык, тема, проверка программы, Happ, выход.

## Telegram

**Способ 1 (рекомендуется).** Telegram Desktop → Настройки → Продвинутые настройки → Тип соединения → **«Использовать системные настройки прокси»**. Telegram и мини-приложения пойдут через программу, а когда она закрыта — напрямую.

**Способ 2 (вручную).** Тип соединения → «Использовать собственный прокси» → SOCKS5, сервер `127.0.0.1`, порт `10808`, логин и пароль пустые. Когда программа закрыта, такой прокси нужно выключать. Порт смотри в «Дополнительно → Данные для подключения».

**Telegram на телефоне.** Включи «Доступ из домашней сети» в «Данных для подключения» и отсканируй телефоном QR-код в «Поделиться → Telegram через этот компьютер». Вручную: Прокси SOCKS5, адрес компьютера и порт `10810` с той страницы, логин и пароль оттуда же.

## Режим TUN

В компьютере появляется виртуальная сетевая карта, и через программу идёт весь трафик: игры, лаунчеры, звонки, программы без настроек прокси. Правила те же: российские сайты напрямую, заблокированные через VPN.

Движки:
- **Авто** — программа сама выберет тот, что работает на этом компьютере, и запомнит его.
- **Xray TUN** — встроен в ядро. В первый раз программа скачает небольшой драйвер wintun.dll с сайта WireGuard и проверит его подпись (SHA-256).
- **Sing-box** — отдельный проверенный движок, скачивается с GitHub.
- **tun2proxy** — простой запасной движок.

Для TUN нужны права администратора: при подключении Windows спросит разрешение, нажми «Да». Если TUN не включится, программа всё равно подключится через системный прокси и покажет причину на значке «!».

**Защита от утечек** (включена по умолчанию): в режиме TUN Windows не даст отправить что-либо мимо программы — ни DNS-запросы, ни IPv6.

**Видео без лагов в режиме TUN** (включено по умолчанию, «Функции → Обход в России»): в режиме TUN протокол QUIC (UDP 443) мимо российских сайтов закрывается. Браузер и YouTube сразу переходят на обычное соединение, которое через VPN работает ровно; QUIC внутри VPN часто подвисает.

## Мультисервер

Некоторые сервисы закрыты для отдельных стран: например, ChatGPT не пускает из одних стран, Spotify — из других. Если сервис не открывается через твой сервер, программа сама найдёт среди лучших серверов тот, где он работает, и пустит через него только этот сервис. Остальное идёт как обычно. Проверка идёт вместе с проверкой сервисов и раз в 3 часа. На странице «Сервисы» видно, какой сервис через какой сервер идёт.

## Свой маршрут для сервиса или сайта

Для каждого сервиса (страница «Сервисы и сайты», колонка «Маршрут») и для любого сайта (страница «Свои правила») можно выбрать, как к нему подключаться:

- **Как по умолчанию** — решает программа (режим маршрутизации, Мультисервер, обход замедлений);
- **Через VPN** — через основной сервер;
- **Напрямую** или **Напрямую с обходом замедления** (zapret или ByeDPI, если включены);
- **Блокировать**;
- **Через другой сервер** — любой сервер из подписки, например американский только для ChatGPT;
- **Через свой прокси** — SOCKS5 или HTTP от продавца прокси, например резидентный прокси для TikTok.

**Свои прокси** добавляются на странице «Свои правила». Подходят адреса вида `socks5://логин:пароль@адрес:порт`, `http://…`, `адрес:порт:логин:пароль`. Программа сама проверит прокси, покажет его IP и страну, проверит, открывается ли TikTok, и даст ссылку на проверку IP в Scamalytics. Если тип не указан, программа сама поймёт, SOCKS5 это или HTTP. По умолчанию к прокси подключаемся **через VPN**: провайдер видит только VPN, а сайт — адрес прокси.

Твой выбор важнее автоматики: Мультисервер и «Исправить автоматически» его не трогают. Если выбранный сервер пропал из подписки или прокси удалён, сайт временно идёт через основной VPN, а рядом появляется предупреждение. Логин и пароль прокси хранятся только на этом компьютере: в журнал, отчёты и файл переноса настроек они не попадают.

## Автоматика

Всё ниже работает само, с лучшими настройками по умолчанию. Каждую функцию можно выключить: «Дополнительно → Функции → Автоматика».

- **Автоподбор для сайтов.** Программа замечает новые сайты и проверяет их в фоне. Не открывается напрямую — сама пускает через VPN. Не открывается через сервер (закрыт для его страны или для адресов VPN) — пробует другие серверы. Правило добавляется на лету, без переподключения. Сайты, которые идут через VPN, напрямую не проверяются: провайдер их не увидит. Найденные правила видны в «Свои правила → Автоподбор для сайтов». Там их можно закрепить (сделать своими) или убрать. Свои правила всегда важнее.
- **Сайты, которые не догружаются.** Частая поломка: страница открывается, а картинки и видео нет. Обычно провайдер пропускает у части адресов (зарубежные хостинги и CDN) только первые ~16 КБ, а потом соединение «замирает». Программа проверяет не только «открывается ли», но и «качается ли», и уводит такие адреса в VPN.
- **«Сайт работает не полностью».** Кнопка в «Сервисы и сайты → Проверить сайт». Открой сайт в браузере и нажми её. Программа соберёт адреса, которые сайт загружал (картинки, видео, CDN), проверит каждый напрямую, через VPN и через другие серверы. Сломанное она пустит туда, где оно работает.
- **Вопрос «сайт не открывается через VPN».** В режиме «Всё через VPN» бывает, что сайт закрыт для всех серверов подписки, а без VPN открывается. Сама программа такой сайт напрямую не пускает и не проверяет (провайдер не должен видеть, куда ты заходишь через VPN), а спрашивает: «Открывать его напрямую?». Ответ «Напрямую» добавляет сайт в «Свои маршруты». Не чаще трёх вопросов за 10 минут, про один сайт — один раз. Неотвеченные вопросы видны в «Сервисы и сайты».
- **Вопрос «сайт закрыт блокировщиком».** Если списки рекламы закрыли сам сайт, который ты открываешь, программа спросит, разрешить ли его. Вопрос приходит в окне программы, а если окно закрыто, то сообщением у значка в трее.
- **Мгновенное переключение.** Запасной сервер заранее загружен в ядро. Если основной замолчал, ядро само уводит соединения на запасной за доли секунды, без переподключения.
- **Предупреждения о подписке.** За 3 дня до конца подписки и когда трафика осталось меньше 10%, приходит уведомление. Каждое — один раз.
- **Профили сетей.** В открытом Wi-Fi без пароля (кафе, аэропорт) программа сама включает VPN и пускает через него всё. Сети можно отметить как «домашнюю» или «чужую» в «Функции → Автоматика → Профили сетей».
- **Умные уведомления.** Когда окно закрыто, важное (сервер упал и заменён, подписка кончается, время VPN вышло) приходит сообщением у значка в трее. Мелочи не беспокоят.
- **История качества серверов.** Программа помнит, в какие часы сервер работал плохо (например, по вечерам), и в это время выбирает его реже.
- **Автообновление программы.** Новая версия скачивается в фоне, проверяется по цифровой подписи и ставится при следующем запуске. Твои данные не трогаются. Работает, когда у программы есть свой репозиторий на GitHub (см. «Свой выпуск на GitHub»).

## Лестница самоподбора

Главная защита от блокировок 2026 года: серверы режут по отпечатку TLS, по подсети хостинга, а «подключено» часто значит «подключено, но пусто». Поэтому успех для программы — это **скачавшиеся через сервер 64 КБ**, а не пинг.

Когда сервер перестаёт работать, программа сама спускается по способам, пока данные не пойдут:
1. то, что работало **в этой сети** (у этого провайдера или в этой сети Wi-Fi);
2. **тот же сервер** (может, это был короткий сбой);
3. **другой отпечаток TLS** — Firefox, Safari, случайный (в мае 2026 блокировали отдельно отпечаток Chrome);
4. **маскировка** — дробление первого пакета;
5. **другой вход** того же сервера (другой порт или транспорт);
6. **другие серверы** — сначала из другой подсети хостинга, потом проверка всех серверов и обновление подписок.

Если включены белые списки, программа начинает сразу с серверов «БС». Способы внутри шага проверяются одновременно, поэтому лестница проходит быстро. Что сработало, видно в «Состоянии» и в журнале («Лестница: данные пошли — отпечаток firefox: …»).

**Ничего не помогло** — программа не переподключается по кругу и не сажает батарею. На главной появляется карточка «Сейчас не работает ни один сервер»: что открывается напрямую (Яндекс, VK, Госуслуги…) и когда следующая попытка (через 2, 5, 10, 20 минут). Кнопка «Попробовать сейчас» — не ждать.

Выключатели в «Функциях → Подключение» (на телефоне — в «Настройках»):
- **Подбор отпечатка TLS** — пробовать Firefox, Safari и случайный и запоминать, какой прошёл у каждого сервера;
- **Сторож данных** — если запросы через VPN уходят, а ответы не приходят 15 секунд, проверить данные и искать рабочий способ, даже когда пинг в порядке;
- **Память сетей** — дома, на работе и на мобильном сразу брать то, что работало именно там. Хранится только отпечаток сети (хеш), без её имени и адреса. «Забыть всё» — там же.

## Движки

Список **«Движок»** на главной выбирает, какие серверы использовать. В скобках — сколько серверов каждого вида.

- **Авто** (по умолчанию) — все серверы, кроме AmneziaWG. Автопереход и лестница перебирают их все, а при сбое сначала пробуют сервер с другим транспортом (TCP ↔ UDP/QUIC): если провайдер режет один, часто проходит другой.
- **Xray** — только VLESS, VMess, Trojan, Shadowsocks, SOCKS.
- **Hysteria2** — быстрый протокол поверх UDP (QUIC), хорошо держит скорость на плохих каналах. Работает прямо в ядре Xray (нужна версия 26.2 или новее — программа обновит ядро сама). Маскировка Salamander поддерживается. Где провайдер режет UDP, Hysteria2 не заработает.
- **sing-box** — TUIC и AnyTLS. Ядро Xray их не умеет, поэтому программа запускает **sing-box как мост**: он скачивается сам при первом подключении и работает без прав администратора. Весь трафик всё равно идёт через ядро Xray — правила, реклама, свои маршруты, статистика и TUN работают как обычно. Сервер TUIC может быть и запасным, и сервером своего маршрута.
- **AmneziaWG** — отдельный VPN: WireGuard с маскировкой (перед подключением шлёт мусорные пакеты и меняет заголовки), провайдер его не узнаёт. Программа включает его **официальным клиентом AmneziaWG для Windows** — поставь его один раз ([страница загрузки](https://github.com/amnezia-vpn/amneziawg-windows-client/releases), кнопка «Скачать клиент» появится сама). Windows спросит разрешение один раз. Пока работает AmneziaWG, через него идёт **весь трафик компьютера**, а правила программы (российское напрямую, реклама, свои маршруты) не действуют — так и написано на главной. В «Авто» AmneziaWG не входит, его включают выбором в списке. Если туннель выключили в самом клиенте, программа покажет «!».

**Как добавить.** «+» → «Добавить сервер» и вставь:
- ссылки `hysteria2://` (или `hy2://`), `tuic://`, `anytls://` — как обычные;
- **конфиг AmneziaWG** — весь текст файла `.conf` (от `[Interface]` до конца);
- **ключ Amnezia** `vpn://…` из приложения AmneziaVPN — программа достанет из него AmneziaWG и/или сервер Xray.

Конфиг AmneziaWG хранится вместе со своими серверами в зашифрованных настройках. Файл для клиента появляется только на время включения и стирается после выключения. Команды `PreUp/PostUp` из конфига выкидываются: с правами администратора они опасны. В отчёты и журнал ключи и адреса не попадают.

**На телефоне** работают Авто, Xray и Hysteria2. AmneziaWG включает его собственное приложение: выбери «AmneziaWG» → «Сохранить файл .conf» → в AmneziaWG «+» → «Импорт из файла». Android держит только один VPN, поэтому VEDOMYJ на это время выключи. TUIC и AnyTLS на телефоне не работают (видны с пометкой «только на компьютере»).

## Состояние

Экран, где видно всё о подключении и защите. Открывается с полосы проверок на главной или из «Дополнительно → Состояние»:
- **вывод** сверху: «Всё в порядке», «Есть замечания» или «Есть проблема» и кнопка **«Проверить всё»** (данные, сертификаты и утечки одной кнопкой);
- **подключение**: сервер, способ, идут ли данные (и за сколько скачались 64 КБ), сеть (запомнен ли для неё способ), что последним делал Автопереход;
- **защита**: сертификаты, утечки, kill switch, шифрование DNS — и подробные проверки сертификатов и утечек;
- **программа**: журнал ошибок и «Проверка программы».

## Защита

- **Kill switch** («Функции → Защита», по умолчанию выключен). Если VPN сломался, сайты, которые должны идти через VPN, не откроются через обычный интернет, пока программа не найдёт рабочий сервер. То, что и так идёт напрямую (российские сайты), продолжает работать.
- **Проверка утечек** («Состояние → Проверка утечек»). Видят ли сайты твой настоящий адрес, через кого идёт DNS, не уходят ли WebRTC и IPv6 мимо VPN. Адреса показываются только в окне — в журнал и отчёты они не пишутся.
- **Пин-код на окно** («Настройки → Конфиденциальность»). Окно открывается только с пин-кодом: после закрытия или через несколько минут без действий. Кнопка в трее и горячая клавиша работают без него. После 5 неверных попыток приходится ждать.
- **Шифрование данных** (включено). Подписки, свои серверы, пароли прокси и данные своего сервера лежат на диске зашифрованными: открыть их может только твоя учётная запись Windows на этом компьютере. Чтобы перенести программу на другой компьютер, используй «Поделиться → файл настроек».
- **Трафик за день и за месяц** — вверху раздела «Трафик»: сколько прошло через VPN и напрямую.
- **Проверка сертификатов** («Состояние → Проверка сертификатов»). Смотрит две вещи:
  1. стоит ли в системе (на телефоне — среди «пользовательских сертификатов») **сертификат Минцифры** — Russian Trusted Root CA / Sub CA. Им можно подписать любой сайт, и браузер подмену не заметит. Обычно его ставят ради Сбербанка и Госуслуг; если он не нужен — программа подскажет, как его удалить. Поставил сам и он нужен — нажми «Понятно», и «!» пропадёт, пока сертификат не сменится;
  2. **не подменяют ли сертификаты сайтов** — у Google, GitHub, Википедии и Cloudflare, напрямую и через VPN. Подмена напрямую — соединения в этой сети перехватывают (пароли — только через VPN). Подмена через VPN — сервер VPN нечестный, смени его. Антивирус, который проверяет HTTPS (Касперский, ESET и др.), показывается отдельно: это не провайдер.

  Программа смотрит только, кто выдал сертификат, — адреса и страницы никуда не пишутся.
- **Слежка за подменой сертификатов** («Функции → Защита», включена). Тихая проверка при смене сети и раз в 6 часов. Нашлась подмена — «!» (на телефоне ещё и уведомление).

## Быстрые действия

- **Горячая клавиша** `Ctrl+Alt+V` включает и выключает VPN из любой программы. Сочетание меняется в «Функциях».
- **«Включить на 1 час»** в меню значка в трее: VPN выключится сам, время видно на главной.

## Приложения

«Свои правила → Приложения»: свой путь для программы целиком (Discord, игры, торрент-клиент). Можно выбрать её из запущенных или вписать имя (`Discord`) или путь к `.exe`. Варианты такие же, как у сайтов: через VPN, напрямую, блок, через другой сервер, через свой прокси. Для известных программ (Discord, Telegram, Steam, Spotify, WhatsApp) есть кнопка «Подобрать»: программа проверит пути и поставит рабочий. Напрямую выбирается первым: так быстрее.

Многие программы (Discord, игры, Zoom) не слушаются системного прокси, поэтому их маршрут работает только в режиме **TUN**. Программа предупреждает об этом. Голос Discord идёт по UDP: через VPN он работает только в TUN. Без TUN голос чинит обход замедлений (zapret).

**Торренты** программа узнаёт сама. По умолчанию они идут напрямую, потому что многие VPN-сервисы блокируют за торренты. Можно выбрать «через VPN» или «блок».

## Маскировка

Иногда провайдер узнаёт VPN-сервер по первому пакету соединения и обрывает его. При проверке серверов программа пробует такие серверы ещё раз с маскировкой: делит первый пакет на кусочки с паузами. Способов два: если первый не помог, пробуется второй (другие размеры кусочков и паузы). Кому это помогло, тот помечен в списке словом «маскировка» и дальше работает с ней.

## Белые списки

Мобильный интернет иногда пускает только на разрешённые сайты (Госуслуги, Яндекс, VK). Программа замечает это сама и переключается на сервер для белых списков: в подписке он обычно так и называется («Обход белых списков», «БС»), в списке он помечен. Когда ограничения снимут, программа вернётся к лучшему серверу.

## Другие устройства

- **Доступ из домашней сети** («Данные для подключения»). Телефон, приставка или другой компьютер в той же Wi-Fi-сети указывают этот компьютер как прокси. Для них есть отдельные порты (10810 и 10811) и логин с паролем, которые программа придумала сама, чтобы чужие в той же сети не пользовались твоим VPN.
- **Telegram на телефоне** — проще всего через QR-код: «Поделиться → Telegram через этот компьютер».
- **Раздать VPN по Wi-Fi** («Данные для подключения»). Компьютер создаёт свою сеть Wi-Fi через «Мобильный хот-спот» Windows. В режиме TUN всё, что к ней подключено, сразу идёт через VPN — даже телевизор и приставка. Подключиться можно по QR-коду сети.

## Шифрование DNS

По умолчанию выключено, включается плиткой на главной. Адреса сайтов программа узнаёт через зашифрованный DNS: российские — через Яндекс напрямую, остальные — через Cloudflare по VPN. Провайдер не сможет подменить сайт или увидеть, куда ты заходишь.

## Блокировка рекламы — с VPN и без

Включается плиткой «Без рекламы» на главной, настраивается в «Дополнительно → Блокировка рекламы».

- **Работает и без VPN.** Когда VPN выключен, программа работает без сервера: реклама не загружается, всё остальное идёт напрямую, IP не меняется. Браузеры фильтруются через системный прокси, а в режиме TUN — все программы и игры.
- **Списки** скачиваются сами и обновляются раз в сутки: основной список рекламы и слежки (HaGeZi) с выбором силы — лёгкая, обычная, сильная, максимальная; отдельно всплывающие окна (рекламные вкладки при клике на плеер), опасные сайты (мошенничество, фишинг) и российская реклама (AdGuard Russian).
- **Не ломает сайты.** По умолчанию сила «Обычная». Встроенная защита никогда не закрывает нужные сайты, даже если они попали в список:
  - большие сайты (Яндекс, VK, YouTube, Google, маркетплейсы и т. п.) остаются открытыми, а их рекламные поддомены блокируются как обычно;
  - хостинги картинок и файлов, Telegram, Discord, GitHub, банки и госуслуги не блокируются целиком.
  
  Если списки закрыли другой сайт, который ты открываешь, программа спросит, разрешить ли его.
- **Слежка Windows и Office** — отдельный список, по умолчанию выключен: телеметрия Microsoft не уходит, обновления Windows работают.
- **Журнал**: что заблокировано и сколько за сегодня; кнопка «Разрешить», если из-за блокировки что-то сломалось.
- **Свои сайты для блокировки**, **исключения** (например, банки) и **пауза** на 5, 30 или 60 минут.
- **«Проверить сайт»**: впиши адрес — программа покажет, какой список его блокирует (основной, всплывающие окна, мошенничество, российская реклама или свои сайты), и предложит «Разрешить». Исключения хранятся в настройках, поэтому переживают обновление списков.
- Блокировка идёт только по точным адресам из списков: слов, шаблонов, правил по путям (`/api/…`) и по оформлению страниц нет. DNS не подменяется — заблокированное соединение просто обрывается, поэтому `nslookup` всегда покажет настоящий адрес.

Чего блокировка по адресам не умеет: реклама в YouTube и VK Видео приходит с тех же адресов, что и видео, — так её не убрать; от рекламы по клику может остаться пустая вкладка. Это полностью убирает расширение uBlock Origin в браузере.

## Обход замедлений YouTube и Discord

YouTube и Discord могут идти не через VPN, а напрямую, на полной скорости твоего интернета. Для этого есть два способа:

- **Zapret** работает для всех программ, включая приложение Discord и голосовые каналы. Windows один раз за запуск спросит разрешение администратора — нажми «Да».
- **ByeDPI** работает как прокси внутри программы и ничего не ставит в систему. Помогает браузерам и Telegram.

В списке «Способ обхода» выбери, как им работать:

- «Zapret, запасной ByeDPI» (по умолчанию);
- «ByeDPI, запасной Zapret»;
- «Только Zapret»;
- «Только ByeDPI»;
- «Выключено».

Одновременно на одних и тех же сайтах они мешают друг другу. Поэтому работает главный способ, а запасной подхватывает, если главный перестал помогать.

Нажми «Подобрать лучшую стратегию»: программа сама скачает нужное, проверит все варианты и включит лучший. Это же делает «Автонастройка». Раз в 5 минут программа тихо проверяет YouTube и Discord. Если перестали открываться, Автопереход сам включает другую стратегию, потом запасной способ, потом пускает их через VPN.

В режиме «Всё через VPN» YouTube и Discord и так идут через сервер, и обход не используется. Он нужен в «Экономном» режиме и без VPN.

## Поделиться

«Дополнительно → Поделиться»:

- **Файл настроек.** Переносит правила сайтов, маршрутизацию, обход замедлений и интервалы обновлений на другой компьютер. Подписки и свои серверы попадают в файл только по галочке, потому что по ним любой сможет пользоваться твоим VPN.
- **QR-код для телефона.** Есть три варианта:
  - подписка для Happ или v2rayNG;
  - один сервер;
  - Telegram через этот компьютер (нужен «Доступ из домашней сети»).

QR-код подписки или сервера есть и в меню «⋯» у подписки и у сервера.

## Автопереход

Каждые 5 секунд программа проверяет соединение. Если сервер завис или стал очень медленным, она переключается на запасной без перезапуска: открытые сайты обычно этого даже не замечают. Запасной сервер виден на плитке и в списке серверов.

## Обновления

Обновления идут аккуратно: в фоне, по одному и только когда программа ничем не занята. Подключение не обрывается: новые списки сайтов и новое ядро начинают работать при следующем подключении.

Ядро, zapret и ByeDPI сначала сверяют номер версии маленьким запросом и скачиваются, только если вышла новая.

По умолчанию:
- серверы — каждые 6 часов;
- списки сайтов — раз в сутки;
- ядро, sing-box и tun2proxy — раз в неделю;
- zapret и ByeDPI — раз в сутки.

Поменять можно в «Дополнительно → Обновления».

### Новая версия поверх старой

1. Скачай архив новой версии (VedomyjVPN-….zip). Распаковывать его не нужно.
2. В папке программы запусти **Обновить.bat** или перетащи архив мышкой на этот файл.
3. Скрипт сам найдёт самый новый архив в «Загрузках», на рабочем столе или рядом с программой, покажет версии и спросит «Обновить?» — нажми Enter.

Что происходит:
- работающая программа аккуратно закрывается и возвращает настройки прокси Windows;
- настройки и подписки копируются в `data/backups` (хранятся три последние копии);
- заменяется только код программы. Папки `data` (подписки, вход в аккаунт подписки, настройки, свои серверы и правила), `bin` (ядро и списки сайтов) и `python` не трогаются;
- программа запускается снова.

Если что-то пошло не так, старая версия и все данные остаются на месте.

## Свой сервер (VPS)

«+» над списком серверов → «Свой сервер (VPS)».

**Мастер «Настроить VPS».** Купи недорогой VPS за границей с Ubuntu, Debian, CentOS, AlmaLinux или Rocky. Впиши его адрес (IP из письма хостинга), порт SSH (обычно 22) и пользователя (обычно root), нажми «Настроить». Откроется окно Windows: введи в нём пароль от сервера и нажми Enter. Символы пароля не отображаются, так и должно быть. Программа пароль не видит и не сохраняет.

Дальше всё само, за 1–3 минуты:
- на сервер ставится Xray официальным установщиком;
- создаются два входа: VLESS + Reality и запасной XHTTP + Reality;
- включается ускорение BBR и открываются порты;
- сервер добавляется в список и сразу проверяется.

Устройств можно подключать сколько угодно.

Подсказки:
- крупные хостинги вроде Hetzner и DigitalOcean в России часто режут, лучше брать небольшие;
- если сервер заблокируют, обычно хватает сменить IP в панели хостинга и запустить мастер ещё раз;
- если в Windows нет ssh: Параметры → Приложения → Дополнительные компоненты → «Клиент OpenSSH».

**Вручную.** Можно вставить ссылку из панели сервера (3x-ui, Marzban, Amnezia) или заполнить поля для Shadowsocks или SOCKS5. Свой сервер блокируют реже, потому что им пользуешься только ты.

**Состояние и ключи для друзей** («Поделиться → Свой сервер»). Сервер, настроенный мастером, программа запоминает (адрес, порт и пользователя — без пароля). Там можно:
- **проверить сервер**: работает ли Xray, сколько подключений, нагрузка, память, место на диске, трафик;
- **дать другу отдельный ключ**: на сервере создаётся новый пользователь, другу показывается QR-код. Ключ можно в любой момент удалить — друг отключится, твой ключ не изменится.

Для каждого действия снова открывается окно ssh для пароля: программа его не хранит. Сервер, настроенный раньше, можно добавить кнопкой «Указать свой сервер». То же самое есть в приложении для телефона.

## Сборки

Всё можно собрать на своём компьютере: дважды щёлкни **Собрать.bat** и выбери, что собрать — Windows, Android или всё сразу. Нужен интернет; в систему ничего не устанавливается. Готовые файлы появятся в папке `dist`, она откроется сама.

**Windows** (1–2 минуты; скачивается встроенный Python с python.org, около 10 МБ):

- `VedomyjVPN-<версия>-setup.exe` — установщик;
- `VedomyjVPN-<версия>-portable.zip` — портативная версия;
- `VedomyjVPN-<версия>-source.zip` — исходники для нейросети, без Python и без папки `data`.

**Android** (первый раз 10–20 минут: скачиваются Java, Android SDK и Gradle, всего около 1,5 ГБ, в папку `%LOCALAPPDATA%\VedomyjVPN-build`; дальше 2–5 минут). Если запущен VEDOMYJ VPN, всё качается через него:

- `VedomyjVPN-<версия>-universal.apk` — для любого телефона (ставь его, если не знаешь, какой нужен);
- `-arm64.apk` — для большинства современных телефонов, `-arm32.apk` — для старых, `-x86_64.apk` — для эмуляторов.

При первой сборке APK создаётся **ключ подписи** (папка `keystore` рядом с инструментами сборки — путь покажется в конце). Сохрани её копию и никому не отправляй: без неё новые версии не встанут поверх старой.

Если что-то не собралось, в папке `dist` будет журнал `windows-build-log.txt` или `android-build-log.txt` — его можно отправить нейросети.

Windows может предупредить, что программа «не распознана»: у самодельных программ нет цифровой подписи. Нажми «Подробнее → Выполнить в любом случае».

## Android

Приложение VEDOMYJ VPN для телефона — в папке `android`. Нужен Android 8 или новее. Умеет то же главное, что программа для компьютера:

- подписки и серверы — по ссылке, QR-коду или из файла настроек с компьютера;
- сам проверяет серверы и подключается к лучшему, при сбое переходит на другой (Автопереход);
- **движки**: Xray и Hysteria2 прямо в приложении, конфиги AmneziaWG — передачей в приложение AmneziaWG (раздел «Движки»);
- маскировка и обход белых списков — тоже сами;
- через VPN идёт весь телефон, включая Telegram и мини-приложения. Российские сайты при этом идут напрямую;
- шифрование DNS;
- **блокировка рекламы — и без VPN**: те же списки, что на компьютере (сила, всплывающие окна, мошенничество, российская реклама), свои сайты, исключения, «Проверить сайт», пауза и счётчик за сегодня. Когда VPN выключен, приложение держит туннель без сервера: реклама блокируется, остальное идёт напрямую. Android разрешает только один VPN — если включить другой VPN, блокировка уступит ему. Можно и совсем без VPN — через «Частный DNS» (подсказка в том же разделе);
- **обход замедлений YouTube и Discord без root**: zapret на Android без root не работает, поэтому ядро Xray само «дробит» начало соединения (как ByeDPI). Программа проверяет несколько способов и берёт самый быстрый, раз в полчаса проверяет его снова; не помогает ни один — сайты остаются через VPN. Может работать и без VPN;
- **свои маршруты**: для каждого сервиса и сайта — через VPN, напрямую, с обходом замедления, через другой сервер, через свой прокси (SOCKS5/HTTP, например резидентный для TikTok; проверка страны и TikTok) или блокировать;
- **«Сайт работает не полностью»** («Свои маршруты»): открой сайт, впиши адрес. Программа проверит всё, что он загружал, и пустит сломанное (картинки, видео) туда, где работает;
- **блокировщик не ломает сайты**: та же встроенная защита, что на компьютере. Если закрыт сам сайт, который ты открываешь, придёт уведомление «разрешить?» (выключается в «Настройки → Автоматика»);
- **скорость** через VPN прямо на главной и в уведомлении, кнопка «Замерить»;
- «Приложения без VPN» — например, банки пойдут напрямую;
- раздача VPN другим устройствам по Wi-Fi, с короткой инструкцией для Android, iPhone, Windows и Telegram;
- свой сервер (VPS) настраивается прямо с телефона; там же — его состояние и отдельные ключи для друзей;
- кнопка в шторке уведомлений, **виджет на рабочий стол** и «Постоянный VPN»;
- в уведомлении VPN — кнопка **«Выключить через 1 ч»** (повторно — «ещё час»);
- **предупреждения о подписке**, **открытый Wi-Fi** — сам предлагает и включает VPN через всё, **проверка утечек** («Проверка программы»);
- **шифрование подписок** ключом телефона и **блокировка приложения** отпечатком или кодом экрана («Настройки → Защита данных»);
- **автообновление приложения** с проверкой подписи (когда есть свой репозиторий);
- «Настройки → Проверка программы»: проверяет телефон, ядро, интернет, подписки, все серверы и сайты напрямую и через VPN, затем кнопкой «Отправить файл отчёта» отдаёт файл `.txt` в Telegram. В отчёте нет ссылок, ключей, адресов серверов и IP.

**Как получить APK.** Проще всего собрать его бесплатно на GitHub, на компьютер ничего ставить не нужно:

1. Создай приватный репозиторий.
2. Загрузи в него папку программы.
3. Открой вкладку **Actions → Android APK → Run workflow**.
4. Через 5–10 минут внизу страницы запуска появится архив **VedomyjVPN-Android**.

Внутри архива бери `VedomyjVPN-…-arm64.apk` — он подходит почти всем телефонам. Если не встанет, бери `universal`. Второй способ — Android Studio: открой в ней папку `android`, затем **Build → Build APK(s)**.

**Ключ подписи.** Новая версия встанет поверх старой, только если APK подписан тем же ключом. При сборке на компьютере ключ создаётся сам (папка `keystore`, путь покажется в конце сборки) — сохрани её копию и никому не передавай. На GitHub ключ берётся только из **секретов** репозитория (`ANDROID_KEYSTORE` и `ANDROID_KS_PASS`, см. «Свой выпуск на GitHub») и никогда не попадает в сам репозиторий, поэтому репозиторий может быть публичным. Без секретов GitHub соберёт APK с временным ключом — поставить его поверх старой версии не выйдет.

**Установка.** Открой APK на телефоне и разреши установку из этого источника. При первом подключении Android спросит разрешение на VPN — нажми «ОК».

## Свой выпуск на GitHub и автообновление

Чтобы программа и приложение обновлялись сами, нужен свой репозиторий на GitHub и ключ подписи выпусков. Делается один раз:

1. Создай ключ выпусков: `python build/release_keys.py`. Он покажет **открытый ключ** (для программы) и запишет **закрытый** в `build/release_key.json`. Содержимое этого файла перенеси в секрет `RELEASE_KEY` (шаг 2), а сам файл удали. Закрытый ключ никому не показывай и не клади в репозиторий.
2. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**:
   - `RELEASE_KEY` — закрытый ключ из шага 1;
   - `ANDROID_KEYSTORE` — ключ подписи APK в base64 (`base64 -w0 release.jks`);
   - `ANDROID_KS_PASS` — пароль от него.
3. Впиши адрес файла выпуска и открытый ключ: `UPDATE_URL` и `PUBLIC_KEY` в `pult/update.py`, `URL`, `PUBLIC_N` и `PUBLIC_E` в `android/.../core/Update.java`.
4. Выпуск: поставь метку версии (`git tag v1.6.0` и `git push --tags`) или запусти **Actions → Release → Run workflow**. GitHub проверит программу, соберёт APK и архив для Windows, подпишет файл выпуска и выложит всё в раздел Releases.

Программа скачивает обновление, только если подпись верна и контрольная сумма файла совпадает, — подменить выпуск, не зная закрытого ключа, нельзя.

## Ссылки на подписку

Подходит обычная ссылка `https://…`, та же, что в Happ, и ссылки-приглашения вроде `happ://add/…`.

**Не подходит** `happ://crypt…`: её может прочитать только Happ. Попроси у провайдера ссылку «для других приложений».

Программа сообщает провайдеру идентификатор устройства (HWID), как Happ. Сообщения провайдера показываются над списком серверов.

**Если адрес подписки заблокирован.** Страница-заглушка провайдера интернета («доступ ограничен…») или ответ без серверов — это не ответ подписки, поиск идёт дальше. Программа пробует по очереди:
1. напрямую;
2. если DNS провайдера «не знает» адрес — узнаёт его через защищённый DNS (Cloudflare, Google) и идёт напрямую по нему;
3. через VPN;
4. через другие рабочие серверы — сначала через российский, если он есть (некоторые серверы подписок пускают только российские адреса). VPN для этого включать не нужно.

Откуда подписка скачалась, видно в журнале. Если не сработало ничего, программа так и скажет: тогда попроси у провайдера VPN запасную ссылку (зеркало).

## Ограничения и блокировки: что программа делает сама

| Что случилось | Что делает программа |
|---|---|
| DNS провайдера «не знает» адрес подписки, списков или GitHub | Берёт адрес у защищённого DNS (Cloudflare, Google, Quad9, AdGuard — к ним подключается по известному адресу, мимо DNS провайдера) и идёт напрямую по нему. Сертификат сайта проверяется как обычно. |
| DNS провайдера не знает имя **VPN-сервера** | Сервер не пропадает: ядро подключается к нему по адресу из защищённого DNS, имя остаётся в TLS и заголовке Host (важно для серверов за CDN). В журнале: «DNS провайдера не знает адрес серверов». |
| Вместо подписки — страница блокировки провайдера | Понимает, что это заглушка, и пробует через VPN и другие серверы. |
| Подписка или список не открываются напрямую | Через VPN, потом через другие рабочие серверы (сначала российский — некоторые серверы пускают только российские адреса). VPN для этого включать не нужно. |
| GitHub открывается не целиком | Списки сайтов качаются с запасных адресов (raw.githubusercontent.com, jsDelivr). Если API GitHub исчерпал лимит запросов (у VPN-серверов адрес общий), номер новой версии ядра берётся со страницы выпуска. |
| Wi-Fi в кафе или гостинице просит войти | Программа видит страницу входа и не включает «всё через VPN» и kill switch, пока ты не войдёшь, — иначе страница бы не открылась. Потом защита включается сама. |
| Часы сбиты | «!» с подсказкой: серверы VMess и защищённые соединения не работают, если часы расходятся больше чем на 2 минуты. |
| Антивирус удалил или заблокировал ядро Xray | Понятное сообщение: добавить папку в исключения или вернуть файл из карантина, потом «Обновить ядро». |
| Белые списки у мобильного оператора | Сама переходит на сервер для белых списков и обратно (см. «Автоматика»). |

## Если что-то пошло не так

- **Пока идёт долгая задача** (подбор стратегии zapret, скачивание списков, проверка серверов), VPN можно включать, выключать и переключать — эти действия идут своей очередью. Если долгой задаче в конце нужно перезапустить VPN, она дождётся окончания твоего действия.

- **Жёлтый «!»** рядом с названием показывает, что случилось и что делать. Там же есть кнопка «Скопировать отчёт для нейросети».
- **«Ещё → Журнал ошибок»** — всё, что сломалось раньше, даже если «!» уже пропал. Оттуда же — заявка на GitHub (см. «Журнал ошибок и заявки на GitHub»).
- **«Состояние → Проверка программы»** (вход — полоса проверок на главной) или файл **Проверка.bat** проверяют всё по шагам: ядро, списки, порты, интернет, подписки, серверы, сервисы, блокировку рекламы, свои маршруты и прокси. Отчёт сохраняется в `data/reports` (последние 10). Кнопка «Показать файл отчёта» открывает его в Проводнике — перетащи файл в Telegram. В отчёте нет ссылок, ключей, адресов, логинов и паролей, а папка пользователя заменена на `%USERPROFILE%`.
- **На телефоне** то же самое: «Настройки → Проверка программы → Отправить файл отчёта».
- **«Полная проверка.bat»** — всё сразу, 5–10 минут, один отчёт `data/reports/full-check-*.txt`:
  1. код программы (самопроверка);
  2. установка и настройки (то же, что «Проверка.bat»);
  3. функции Windows (то же, что «Проверка новых функций.bat»);
  4. блокировки в этой сети: подменяет ли провайдер DNS и сертификаты сайтов, стоит ли сертификат Минцифры, проходит ли UDP за границу, не включены ли белые списки;
  5. VPN в бою: через три лучших сервера — идут ли данные на самом деле («подключено, но пусто» видно сразу), скорость, какие отпечатки TLS (chrome, firefox, safari, edge, случайный) проходят, работает ли UDP через VPN (звонки, игры), не подменяет ли сервер сертификаты сайтов и какие сервисы открываются.

  Настройки не меняются, системный прокси не трогается: серверы проверяются своим временным ядром. `Полная проверка.bat --quick` — без шагов 1 и 3 (2–4 минуты), `--no-net` — без попыток открыть заблокированные сайты напрямую (провайдер видит такие попытки). В отчёте нет ссылок, ключей и адресов.
- **Сайт без VPN и в другом VPN открывается, а через этот — нет.** Обычно сайт закрыт для адресов твоего сервера. Открой «Сервисы и сайты → Проверить сайт», вставь адрес и нажми «Проверить»: программа найдёт сервер, через который он работает, или пустит его напрямую. Если проверка пишет «Сайт отвечает», а он всё равно не работает, выбери под результатом «Напрямую» или другой сервер.
- **Сайт открывается, а видео или картинки нет.** Обычно провайдер замедляет зарубежный сервер с видео. Выбери в «Маршрутизации» «Всё через VPN» (по умолчанию) или открой «Сервисы и сайты → Проверить сайт» и нажми «Работает не полностью» — программа найдёт адреса сайта и пустит сломанное через VPN.
- **Лагает видео в режиме TUN.** Проверь, что включено «Видео без лагов в режиме TUN» в «Функциях → Обход в России». На телефоне — «Видео без подвисаний» в настройках.
- **«Порт занят».** Закрой Happ, v2rayN и другие VPN-клиенты или поменяй порты в «Данных для подключения».
- **Антивирус ругается на xray.exe, winws.exe или WinDivert.** Это ложное срабатывание, добавь папку `bin` в исключения.
- **Режим TUN не включается.** Нажми «Да», когда Windows спросит разрешение. Если не помогло, выбери в «Подключении» другой движок. Если перестали работать виртуальная машина или другой VPN, выключи «Защиту от утечек» в «Функциях».
- **Zapret не включается.** Когда Windows спросит разрешение администратора, нажми «Да». Если не хочешь давать права, выбери «Только ByeDPI».
- **После аварийного закрытия пропал интернет.** Запусти программу ещё раз, она сама восстановит настройки прокси.

## Журнал ошибок и заявки на GitHub

Программа сама записывает всё, что пошло не так, — чтобы это можно было починить в следующей версии:
- **сбой** — неожиданная ошибка в коде, с технической трассировкой (что и где сломалось);
- **проблема** — жёлтый «!» (сервер упал, ядро не запустилось, подписка не загрузилась, подмена сертификатов…);
- **проверка** — «Проверка программы» или «Полная проверка» нашла ошибки.

Одинаковые записи склеиваются (растёт счётчик «×N»), хранится до 300 последних. Файл — `data/errors.jsonl` (на телефоне — внутри приложения).
**Ссылок, ключей, адресов серверов, IP, логинов и папки пользователя в журнале нет** — программа вычищает их перед записью.

Где смотреть: на ПК — **«Ещё → Журнал ошибок»**, на телефоне — **«Настройки → Журнал ошибок»**.

**Заявка (Issue) на GitHub в одну кнопку.** Один раз впиши адрес своего репозитория (`https://github.com/имя/vedomyj-vpn`) — или он возьмётся сам из адреса обновлений. Дальше «Отправить заявку на GitHub» откроет браузер с готовой заявкой: версия, система и последние записи журнала. Допиши, что делал перед ошибкой, и нажми «Submit». Без репозитория кнопка просто копирует текст заявки — его можно вставить куда угодно (например, нейросети).

## Проект на GitHub

Если выкладываешь программу на GitHub (можно приватным репозиторием):
- **Что не попадает в репозиторий** (см. `.gitignore`): папка `data` (подписки, настройки, журналы), скачанные ядра в `bin`, ключи подписи. Ключи хранятся только в секретах GitHub.
- **Самопроверка при каждом изменении** (`.github/workflows/tests.yml`): GitHub прогоняет проверку программы для ПК и ядра Android. Зелёная галочка у коммита — всё в порядке, красный крестик — открой запуск во вкладке **Actions** и посмотри, какой пункт с «ОШИБКА».
- **Проверка на настоящей Windows** (`.github/workflows/windows.yml`): самопроверка на Windows, настоящие ядра Xray и sing-box проверяют все настройки, которые собирает программа (включая Hysteria2 и мост для TUIC/AnyTLS), а официальный клиент AmneziaWG включает и выключает тестовый туннель. Серверы — только поддельные адреса, интернет машины GitHub туннель не трогает. Отчёт — в разделе **Artifacts** запуска. То же самое на своём компьютере: «Проверка новых функций.bat».
- **APK для телефона** (`.github/workflows/android.yml`): собирается сам при изменениях в папке `android`, готовый файл — в **Artifacts** запуска.
- **Заявки об ошибках**: во вкладке **Issues** есть шаблоны «Ошибка» и «Идея». Заявки из программы приходят с меткой `bug`.
- **Что нового**: перед выпуском допиши в `CHANGELOG.md` раздел `## <версия> — Android <версия>`. Он станет описанием выпуска и текстом в окне «Есть обновление». Если раздела нет, самопроверка покажет ошибку.
- **Выпуск** — см. «Свой выпуск на GitHub и автообновление» выше.

## Конфиденциальность

Ссылки на подписки и настройки хранятся только у тебя, в папке `data`, и по умолчанию зашифрованы. Интерфейс работает только на этом компьютере (127.0.0.1) и защищён секретным ключом. Не передавай папку `data` другим людям.

Сама программа в интернет ходит только за тем, что ей нужно для работы: подписки, списки сайтов, обновления ядра и программы, проверка серверов и сайтов. Проверка утечек обращается к ip-api.com и серверу STUN Google — только когда ты её запускаешь.
